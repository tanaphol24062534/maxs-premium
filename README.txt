สำนักเซียนหมี — แลนดิ้งเพจเติมเกม / บัตรเติมเงิน / Gift Card / บัตรส่วนลด
=======================================================================

1) ใส่ลิงก์ก่อนใช้งาน
   เปิดไฟล์  config.js  ด้วยโปรแกรมแก้ไขข้อความใดก็ได้
   ใส่ลิงก์ระหว่างเครื่องหมาย "" ของแต่ละช่องดังนี้

   ENTRY_URL      ลิงก์ทางเข้าเว็บไซต์  (ปุ่ม "เข้าเว็บไซต์" และ "เติมเลย" ทั้งหน้า)
   LINE_URL       ลิงก์ไลน์ เช่น https://line.me/ti/p/~ไอดี หรือ https://lin.ee/xxxx
   FACEBOOK_URL   ลิงก์เพจเฟซบุ๊ก เช่น https://facebook.com/ชื่อเพจ
   PHONE          เบอร์โทร เช่น 0812345678  (ไม่ต้องพิมพ์ tel: ระบบใส่ให้เอง)
   TELEGRAM_URL   ลิงก์เทเลแกรม เช่น https://t.me/ชื่อผู้ใช้

   ช่องที่ยังไม่พร้อม ปล่อยว่าง "" ได้ ปุ่มนั้นจะถูกซ่อนไว้

2) ใส่ Facebook Pixel สำหรับยิงแอด
   เปิดไฟล์  config.js  แล้วใส่ Pixel ID ในช่อง  FB_PIXEL_ID
   (ตัวเลขล้วน จาก Events Manager เช่น "123456789012345")
   เว็บจะนับ PageView อัตโนมัติเมื่อเปิดหน้า
   ปุ่ม "เข้าเว็บไซต์" / "เติมเลย" จะนับเป็น Lead
   ปุ่มติดต่อ (เฟซบุ๊ก ไลน์ เทเลแกรม โทร) จะนับเป็น Contact
   ถ้ายังไม่พร้อม ปล่อยว่าง "" ได้ หน้าเว็บยังใช้งานปกติ

3) ดูตัวอย่างบนคอมพิวเตอร์
   เปิดไฟล์ index.html ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

4) อัปโหลดขึ้นเน็ต (เลือกอย่างใดอย่างหนึ่ง)

   • Netlify (ง่ายสุด)
     เข้า https://app.netlify.com/drop
     ลากทั้งโฟลเดอร์นี้ไปวาง แล้วจะได้ลิงก์ทันที

   • Cloudflare Pages
     เข้า https://pages.cloudflare.com/
     กด Create แล้วอัปโหลดโฟลเดอร์นี้ (หรือเชื่อม GitHub)

   • GitHub Pages
     สร้าง repo ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดขึ้นไป
     ที่ Settings > Pages เลือก branch หลัก และโฟลเดอร์ / (root)
     เว็บจะอยู่ที่ https://ชื่อผู้ใช้.github.io/ชื่อrepo/

หมายเหตุ: ต้องอัปโหลดทั้งโฟลเดอร์ (index.html, config.js และโฟลเดอร์ assets)
อย่าแยกไฟล์ออกจากกัน
